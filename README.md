# sacred-numerology

Skill «Сакральная нумерология»: пифагорейская нумерология (кириллица + латиница), кармические долги и уроки, личные циклы, ведические Наваграхи, славянские акценты.

Быстрый старт:
```bash
python3 scripts/calculate.py --date 15.08.1990 --name "Иван Иванов" --on 2026-11-01 --format text
python3 scripts/run_evals.py
```
Платформенные версии: `platform-adaptations/` (Gemini, ChatGPT, Claude) + VERIFICATION-REPORT.md.
Эзотерическая традиция, научных доказательств нет.
